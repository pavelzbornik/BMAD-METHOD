# Funnel Optimization Playbook

Purpose: diagnose and improve conversion funnels using analytics, experiments and UX improvements.

1. Baseline
   - Capture funnel steps and baseline conversion rates (`tasks/funnel-diagnosis.md`).

2. Segment
   - Use `tasks/build-segmentation-matrix.md` to find high-impact cohorts.

3. Hypothesize
   - Produce quick experiments (`templates/growth-experiment-tmpl.yaml`) with clear metrics.

4. Test
   - Run A/B tests, measure with `tasks/retention-cohort-analysis.md` and dashboards.

5. Rollout
   - Promote winning variants and monitor long-term retention.

Artifacts:

- funnel-baseline.md
- experiments-log.md
