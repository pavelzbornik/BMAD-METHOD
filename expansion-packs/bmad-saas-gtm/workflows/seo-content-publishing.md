# SEO Content Publishing Playbook

Purpose: a repeatable process for researching, drafting, optimizing, and publishing SEO content.

1. Research
   - Run `tasks/keyword-research.md` and build keyword universe.
   - Prioritize by search intent, difficulty, and business value.

2. Draft
   - Use `templates/seo-content-brief-tmpl.yaml` and `templates/messaging-framework-tmpl.yaml`.
   - Include internal linking plan and target CTAs.

3. Review & Optimize
   - Run `checklists/seo-technical-checklist.md` and content quality checks.
   - Validate schema and metadata.

4. Publish
   - Schedule publishing and set canonical tags.
   - Add tracking UTM and search console verification.

5. Measure & Iterate
   - Monitor ranking changes and conversion lift; create experiments where needed.

Artifacts:

- seo-brief.md
- published-url-list.md
