# Experiment Quality Checklist
- [ ] Hypothesis explicit (mechanism + metric + magnitude)
- [ ] Primary metric tied to business outcome layer
- [ ] Guardrail metrics enumerated
- [ ] Segmentation plan pre-defined
- [ ] Event schema stable (no mid-test changes)
- [ ] Minimum detectable effect sized
- [ ] Runtime estimate realistic
- [ ] Kill criteria pre-registered
- [ ] Ethical / user trust considerations documented
