# Landing Page Conversion Checklist
- [ ] Single dominant CTA above fold
- [ ] Headline = Outcome not Mechanism
- [ ] Problem tension section present
- [ ] Social proof early & credible
- [ ] Objection handling covers top 5 friction points
- [ ] Visual hierarchy matches scanning patterns (F/Z)
- [ ] Mobile layout parity considerations
- [ ] Performance budget respected
- [ ] Tracking plan (scroll, CTA click, form start, form submit)
