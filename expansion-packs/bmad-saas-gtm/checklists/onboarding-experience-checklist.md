- [ ] First value path ≤ 5 required steps
- [ ] Empty states contextual & instructive
- [ ] Friction audit performed

- [ ] Guardrails: no spam/overlapping messages
- [ ] Instrumentation covers each stage transition
- [ ] Drop-off recovery prompts planned
